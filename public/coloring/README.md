# Раскраски My Living World

Первый набор шаблонов для печати. Каждый лист рассчитан на A4 и содержит четыре угловых маркера. Ребёнок должен оставить маркеры белыми и раскрашивать только центральную область.

## Набор
- `rocket.svg` — ракета
- `car.svg` — машинка
- `train.svg` — поезд
- `trex.svg` — ти-рекс

На следующем этапе capture pipeline будет искать эти четыре маркера, выпрямлять перспективу и извлекать центральную область рисунка. Подход повторяет проверенную концепцию Paper Aquarium: четыре угловых маркера позволяют определить лист и исправить перспективу перед переносом рисунка на 3D-модель. citeturn0search0
