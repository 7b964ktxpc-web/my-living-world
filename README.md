# 🌍 My Living World

Interactive children's world where hand-drawn and colored creations come alive in 3D.

## Worlds

- 🚀 Space
- 🚗 Cars
- 🚂 Trains
- 🦖 Dinosaurs

## Vision

Child creates a drawing → camera captures it → the system recognizes the template → the colored artwork becomes a living 3D object → the object joins the child's world.

This project is inspired by the interaction concept demonstrated by [Paper Aquarium](https://github.com/MrMoT9I/paper-aquarium), but is being developed as an original multi-world experience.

## MVP roadmap

1. Interactive 3D worlds
2. Printable coloring templates
3. Camera capture and page detection
4. Artwork extraction and texture mapping
5. Personal collection of creations
6. Phone-as-controller / TV mode
7. AI-assisted recognition of custom drawings
8. Missions, sounds, animations and progression
